# Три варианта стиля (на выбор)

На сайте вверху есть переключатель **A / B / C**. Структура, тексты и функции одинаковые, разное только оформление.

## A. «Документ»
Мир официальных бланков и талонов: защитная «волна» на фоне шапки, нумерованные поля для шагов (01, 02, 03), пунктирные разделители. Дата проверки фактов стоит как **фиолетовая печать** «Проверено», которая «ставится» при прокрутке.
Шрифты PT Serif / PT Sans (их создавали для госдокументов). Ощущение: надёжно, официально, по-банковски.
Риск: может показаться строгим.

## B. «Маршрут»
Мир схемы метро: у каждого раздела свой цвет линии, страницы — станции, линия заполняется по мере прокрутки, «двери» на главной — станции на линии.
Шрифт Golos. Ощущение: современно, понятно, «иду по шагам».
Риск: ярче остальных; цветов много.

## C. «Тетрадь адаптации»
Мир блокнота специалиста по адаптации: клетка на фоне шапки, рукописные пометки, маркер-выделения главного, линии, которые сами прорисовываются.
Шрифты Onest + рукописный Neucha. Ощущение: тепло, по-человечески, «вас ведут за руку».
Риск: меньше «банковской» строгости.

## Общее для всех
- Сначала телефон: нижняя панель под большой палец (Главная, Вопросы, Поиск, Меню), меню выезжает снизу.
- Плавные переходы между страницами (встроены в браузер, сайт от них не тяжелеет).
- Гид-подсказка с блоком «Коротко» на каждой странице. Внешний вид гида пока нейтральный, его можно заменить на маскота или человека.
- Если в телефоне включено «уменьшить движение», анимации выключаются.

После выбора лишние два варианта удаляю, а выбранный довожу до финала.
