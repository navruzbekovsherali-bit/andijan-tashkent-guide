# Правила текстов гайдбука

## Где лежат тексты
`src/content/guide/ru/<slug>.md` — один файл = одна страница. Английская и узбекская версии потом будут лежать в `en/` и `uz/` с тем же `slug`.

## Шапка файла (frontmatter)
```yaml
---
title: 'Первые 72 часа после прилёта'      # короткий заголовок, без эмодзи
description: 'IMEI, SIM-карта, регистрация и связь с HR — по шагам.'  # 1 предложение, до 140 знаков
audience: [expat]          # [local], [expat] или [local, expat]
section: arrival           # см. список разделов ниже
order: 20                  # порядок внутри раздела (10, 20, 30…)
checked: 2026-10-26        # только если на странице есть сроки, суммы, законы или цены
needsConfirmation: true    # только если есть пункты ⚠️ из audit.md
sources:                   # официальные источники из audit.md (если есть)
  - title: 'Закон о регистрации ЗРУ-1074'
    url: 'https://lex.uz/ru/docs/7627933'
tldr:                      # «Коротко»: 2–4 пункта, самое важное
  - 'Задекларируйте телефон на таможне — иначе платёж 30% от цены.'
faq:                       # 2–5 вопросов-ответов (идут в общий FAQ и в будущего чат-бота)
  - q: 'Сколько дней на регистрацию IMEI?'
    a: 'Точный срок уточните на uzimei.uz…'
---
```

### Разделы (`section`)
| section | Название в меню |
|---|---|
| start | Начало |
| arrival | Переезд и прибытие |
| first-days | Первые дни в банке |
| work | Работа и деньги |
| living | Жизнь в Узбекистане |
| family | Семья и дети |
| country | Об Узбекистане |
| travel | Отдых и поездки |
| help | Помощь и контакты |

## Как писать
1. **Всегда на «вы»**: «Возьмите паспорт», а не «Возьми». Тёплый, вежливый, ясный тон.
2. **Логика: что делать → когда → куда идти.** Шаги — нумерованным списком. Главное наверху.
3. **Короткие абзацы** (2–3 предложения). Подзаголовки `##` и `###`. Без эмодзи в заголовках.
4. **Убрать мусор из Notion:** следы ИИ («Информация на ваших слайдах…», «Может, мне помочь…?», «Hero Section», «на отдельном слайде»), фальшивые ссылки (`google.com/search?q=`, `id123456789`, `goo.gl/uXv7…`, пустой `instagram.com/`), повторы, «хвостики» вроде «Твой гид по…».
5. **Пустые заготовки** (`[телефон]`, `[адрес]`, `[дресс-код]`…) не выдумывать. Писать: «Уточните у специалиста по адаптации.»
6. **Факты** брать из `docs/audit.md`:
   - ✅ — оставить;
   - ✏️ — заменить на новое значение;
   - ⚠️ — написать осторожно («по данным на октябрь 2026 г.; уточните у HR») и поставить `needsConfirmation: true`.
7. **Ссылки** — только проверенные из раздела 7 audit.md или официальные домены (`*.uz`, сайт банка). Если сомневаетесь — без ссылки.
8. **Ничего не придумывать:** цифры, адреса, названия школ, ресторанов и клиник — только из Notion. Если название не проверено (школы, сады, рестораны), добавить в конце страницы строку: «Список составлен адаптационной командой и носит рекомендательный характер. Перед визитом уточните адрес и условия.»
9. **Блоки-подсказки:** используйте цитату Markdown с меткой в начале:
   - `> **Важно.** …` — предупреждение;
   - `> **Совет.** …` — полезный совет;
   - `> **Уточните у HR.** …` — пункт ⚠️.
10. **Таблицы** допустимы, но не шире 3 колонок (сайт читают с телефона).
11. **Объём:** не длиннее исходника; лучше короче и яснее.
