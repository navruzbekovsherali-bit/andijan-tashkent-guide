# Гайдбук Hamkorbank — сайт

Статический сайт на Astro. Живёт только в этой папке и не связан со старым сайтом в корне репозитория.

## Как поменять текст
1. Откройте файл страницы: `src/content/guide/ru/<страница>.md` (на GitHub — значок карандаша).
2. Поменяйте текст. Шапку между `---` трогайте аккуратно: там название, описание, «Коротко» и вопросы для FAQ.
3. Сохраните (Commit). Сайт пересоберётся сам после подключения Vercel.

Правила текстов: `docs/content-guide.md`.

## Команды (для программиста)
```
npm install
npm run dev      # локально: http://localhost:4321
npm run build    # сборка в dist/
node scripts/make-preview.mjs   # предпросмотр с относительными ссылками (папка preview/)
```
Нужен Node.js ≥ 22.22.

## Что где
| Путь | Что это |
|---|---|
| `src/content/guide/` | Тексты страниц (ru, потом en, uz) |
| `src/lib/i18n.ts` | Надписи интерфейса на трёх языках |
| `src/styles/global.css` | Цвета (глазури), шрифты, движение |
| `src/lib/girih.ts` | Геометрия узора «звезда и крест» |
| `src/pages/` | Шаблоны страниц |
| `/search-index.<lang>.json` | Индекс поиска |
| `/api/guide.<lang>.json` | Все тексты, FAQ и источники одним файлом — для будущего чат-бота |
| `docs/` | Карта гайдбука, аудит фактов, решения, вопросы юристу/HR |
| `PLAN.md` | План работ |

## Публикация (Vercel)
Новый проект → репозиторий `andijan-tashkent-guide` → **Root Directory: `guidebook`** → Deploy. Настройки Astro Vercel определит сам.
