## Завтра начинаем с
1. Открыть предпросмотр, переключить A / B / C, выбрать стиль.
2. Ответить: какой будет гид (маскот, человек или значок).
3. Открыть доступ к сайтам-примерам в настройках окружения (Network access → Full), чтобы я их посмотрел.
4. Передать `docs/for-lawyer-hr.md` юристу и HR.

## Этап 2. Проверка актуальности
1. Выписать из гайдбука все пункты, которые могут устареть: законы, сроки, суммы, пошлины, регистрация, IMEI, налоги, праздники, контакты, цены.
2. Сверить каждый пункт с официальными источниками: lex.uz, gov.uz, my.gov.uz, сайты министерств, таможни и банка.
3. Записать результат в `docs/audit.md`. По каждому пункту: что было, что сейчас, ссылка, дата проверки, статус (✅ верно / ✏️ обновить / ⚠️ подтвердить у юриста или HR).
4. **Вы проверяете audit.md** и решаете, что исправляем. Notion меняем только с вашего разрешения.

## Этап 3. Сайт
1. **Варианты стиля.** Impeccable помогает собрать 2–3 варианта (цвета, шрифты, настроение). Вы выбираете один.
2. **Каркас.** Astro, статический сайт. Отдельная папка для текстов в Markdown: `content/ru`, `content/en`, `content/uz`.
3. **Главная страница** с выбором «Я локальный кандидат» / «Я экспат».
4. **Разделы.** Тексты переносим из Notion с учётом audit.md, без заготовок, битых ссылок и следов ИИ.
5. **Навигация.** Выдвижное меню, поиск по сайту и раздел «Частые вопросы» с поиском.
6. **Мобильная версия в первую очередь**: крупные кнопки, всё удобно одной рукой, быстрая загрузка. Потом версия для ПК.
7. **Анимации**: плавные, лёгкие, без тормозов на телефоне.
8. **Языки.** Готовим места под RU / EN / UZ. Сначала русский, переводы потом.
9. **Задел под чат-бота.** Каждая страница и каждый вопрос из FAQ хранятся в виде понятных карточек (`faq.json`, `search-index.json`), чтобы потом бот мог отвечать по ним.
10. **Проверка**: телефон, ПК, скорость, доступность, все ссылки.

## Этап 4. Публикация
- Бесплатный хостинг Vercel, отдельный проект. Root Directory = `guidebook`.
- Своя ссылка, например `hamkor-guidebook.vercel.app`.
- Пошаговая инструкция для вас.

## Этап 5. Чат-бот (позже)
Бот будет отвечать на вопросы по текстам гайдбука и FAQ. Данные для него заложим на этапе 3.

## Команда агентов (для этапа 3)
Claude работает как дирижёр. Помощников пишем сами, файлы лежат в `guidebook/.claude/agents/`. Чужие наборы из интернета не ставим.
| Роль | Что делает |
|---|---|
| Архитектор | Структура проекта, данные, поиск, задел под бота |
| Креативный директор / дизайнер | Стиль, цвета, шрифты, анимации (через Impeccable) |
| Программист | Собирает страницы и компоненты |
| Редактор и факт-чекер | Тексты, проверка фактов, удаление «мусора» |
| Переводчик | EN и UZ версии |
| Тестировщик | Телефон и ПК, скорость, доступность, ссылки |
