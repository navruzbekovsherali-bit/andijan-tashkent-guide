## Ish jadvali

Bank besh kunlik ish haftasi boʻyicha ishlaydi — haftasiga 40 soat.

| | Vaqt |
|---|---|
| Ish kunining boshlanishi | 08:30 |
| Tushlik | 12:30–13:30 |
| Ish kunining tugashi | 17:30 |
| Dam olish kunlari | shanba va yakshanba |

Agar jadvalingiz standartdan farq qilsa, tafsilotlarni HRdan aniqlang.

## 2026-yildagi bayram va dam olish kunlari

Bu kunlarda butun mamlakat rasman dam oladi. Safarlar va yaqinlar bilan uchrashuvlarni oldindan rejalashtiring.

| Sana | Bayram |
|---|---|
| 1-yanvar | Yangi yil |
| 2-yanvar | Qoʻshimcha dam olish kuni |
| 8-mart | Xalqaro xotin-qizlar kuni |
| 20-mart | Ramazon hayiti |
| 21-mart | Navroʻz |
| 9-may | Xotira va qadrlash kuni |
| 27-may | Qurbon hayiti |
| 28–29-may | Qoʻshimcha dam olish kunlari |
| 31-avgust | Qoʻshimcha dam olish kuni |
| 1-sentabr | Mustaqillik kuni |
| 1-oktabr | Oʻqituvchi va murabbiylar kuni |
| 8-dekabr | Konstitutsiya kuni |

Hayit sanalari va qoʻshimcha dam olish kunlari Prezidentning 24.12.2025 yildagi PF-257-son farmoni bilan belgilangan.

> **HR bilan aniqlang.** Agar bayram dam olish kuniga toʻgʻri kelsa, dam olish kuni koʻchiriladi. 2026-yil oktabr holatiga koʻra, 2026-yilda 9-mart, 23-mart va 11-may ham dam olish kuni boʻldi. Koʻchirishlarni farmon bilan solishtiring yoki HRdan aniqlang.

## Taʼtil

- **Necha kun.** Mehnat kodeksiga koʻra eng kam yillik taʼtil — **21 kalendar kun** (216-modda). Bizning bankda — **28 kalendar kun**.
- **Bayramlar** taʼtil kunlariga kirmaydi.
- **Staj uchun qoʻshimcha taʼtil** (220-modda): har 5 yillik ish uchun 2 kun, lekin 8 kundan koʻp emas.
- **Birinchi taʼtilni** **6 oy** ishlagandan keyin olish mumkin (227-modda). Ish beruvchi bilan kelishuvga koʻra — oldinroq.

> **Maslahat.** Taʼtil sanalarini rahbar bilan oldindan kelishing. Shunda jamoa vazifalarni taqsimlashga ulguradi, siz esa ish qoʻngʻiroqlarisiz xotirjam dam olasiz.

Moddalar yangi Mehnat kodeksiga koʻra koʻrsatilgan (30.04.2023 dan amal qiladi).
