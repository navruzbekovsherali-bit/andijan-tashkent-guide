To work at Hamkorbank you will need access to several systems. Below is how to get it, how to set up your first login and where to go for help.

## Main systems

- **Internal banking platform:** the main workspace for operations and working with customers.
- **IceWarp corporate email:** for emails and work correspondence.
- **EDMS (ЭДО):** the electronic document management system for internal documents and approvals.
- **Microsoft Office:** the standard set of office apps.
- **Task and project systems:** these depend on your department; your manager will tell you about them.

## How to get access

1. **Basic access** is set up in time for your first working day.
2. **Specialised software** for your department: your manager submits a request to the IT service.
3. **Timing:** usually **1 to 3 working days** from when the request is submitted.

## First login

1. Get a temporary username and password from HR or an IT specialist.
2. Change the password at first login. Requirements: at least 8 characters, upper- and lower-case letters, numbers and special characters.
3. Set up two-factor authentication (2FA) following the IT department's instructions.
4. If a program you need is missing from your computer, IT specialists will install it remotely.

## If something does not work

- **IT Service Desk:** technical questions and login errors.
- **Your manager or Buddy:** will help you understand how to work in the banking software itself.
- **The "Help" section** (Справка) inside the systems: it often has ready answers.
